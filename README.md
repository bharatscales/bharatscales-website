# BHARATSCALES Website

Official website for **BHARATSCALES** — software solutions for Indian industries.

## Quick Start

Open `index.html` in your browser, or run a local server:

```bash
# Python
python -m http.server 8080

# Node.js (npx)
npx serve .
```

Then visit `http://localhost:8080`

## Project Structure

```
bharatscales/
├── index.html    # Main page
├── styles.css    # All styling
├── script.js     # Interactivity
└── README.md     # This file
```

## Sections

- **Hero** — Company intro and key stats
- **Services** — ERP, automation, analytics, cloud, mobile, integration
- **About** — Mission and values
- **Industries** — Sectors served
- **Contact** — Inquiry form

## Customization

Update contact details in `index.html` (email, phone, location) and adjust hero stats to match your real numbers.

## Deployment

Deploy to any static host: GitHub Pages, Netlify, Vercel, or your own server. Upload all files in this folder.
